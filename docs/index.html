Muammo

"O'tgan oy o'sha shartnoma haqida nima gaplashgandik?"

Telegram bu savolga javob bermaydi. Qidiruvi so'z bo'yicha ishlaydi: aniq qaysi so'z ishlatilganini eslashingiz kerak. Eslay olmasangiz — yillik arxiv siz uchun yopiq.

Kanal yuritsangiz muammo ikkilanadi. Qaysi post ishladi, qachon chiqarish kerak, keyingisi nima haqida — bularning javobi xabarlar ichida yotibdi, lekin uni qo'lda sanab chiqib bo'lmaydi.

Qanday ishlaydi

To'rt qadam, birinchisidan keyin hammasi avtomatik.

Akkauntingizga ulanadi

Telethon orqali MTProto ulanishi — bot emas, o'zingizning akkauntingiz. Shuning uchun barcha chatlar, shu jumladan yopiq guruhlar ham ko'rinadi.

Arxivni bazaga yig'adi

Xabarlar PostgreSQL'ga tushadi, pgvector bilan vektorga aylantiriladi. Sinxronizatsiya fonda, Redis navbati orqali ishlaydi.

Siz savol berasiz

Oddiy bot chatida, o'z tilingizda. "O'tgan hafta eng ko'p ko'rilgan post qaysi?" yoki "Shartnoma haqidagi gaplarni yig'ib ber".

Agent topadi va xulosa qiladi

Gibrid qidiruv: to'liq matn qidiruvi va semantik qidiruv birga. Topilgan xabarlarni LLM o'qiydi va javobni Telegram formatida qaytaradi.
